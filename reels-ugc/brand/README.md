# Brand de la chaîne

**En attente : c'est la créatrice / le créateur de la chaîne qui fournit l'identité.** Rien ici ne doit être inventé.

À ranger ici dès réception :
- `logo/` : logo et icône **tels quels** (PNG transparent ou SVG) — jamais retapés en texte ni recolorés ;
- `fonts/` : polices converties en `.woff2` ;
- `frame.md` : couleurs exactes (HEX), typographie, composants (cartes, pastilles, boutons, curseur,
  notifications, mockups téléphone / DM / e-mail / facture / contrat) écrits **uniquement** à partir du brand reçu ;
- `planche-controle.png` : planche logo + couleurs + polices + 2 composants, validée avant usage.

Info manquante (couleur d'accent, police de titre…) → la demander, ne pas l'inventer.
